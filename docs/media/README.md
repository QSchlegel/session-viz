from the repository README. `delivery-audit-hero.jpg` is its 10-second poster

[`QSchlegel/session-viz-cloud`](https://github.com/QSchlegel/session-viz-cloud/tree/codex/delivery-assurance-gtm/services/video).

[Mixkit Stock Music Free License](https://mixkit.co/license/#musicFree); the
standalone music file is not stored in this repository.
